Styler Typst HTML

Turn a Word file into an HTML + CSS project

The pages use the Typst template layout and are drawn by the browser itself, so Bangla shapes perfectly. Edit the HTML or CSS here and the pages update. Print to save the PDF. The downloaded folder works on its own: open its index.html in Chrome.

What you get

  • index.html — the content, one element per block
  • style.css — page, header, footer, MCQ and CQ styles
  • engine.js — lays the content out on pages
  • fonts.css — Kalpurush · images/ — pictures · templates/ — logos
  • questions/ — MCQ / CQ sheets, cropped question pictures, media and media_color (like the scraper and the Typst converter)
